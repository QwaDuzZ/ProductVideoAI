## Цель

Подготовить площадку: Supabase Free (MVP), Render (Cron Worker), CI, окружения dev/prod, все секреты вне кода.

## Что сделать

- Создать проект Supabase; включить RLS-режим по умолчанию.
- Render: Cron Job для FFmpeg-воркера (каждые 5 мин, `MAX_TASKS_PER_RUN=3`), подключение через Supavisor Transaction Pooler, порт 6543, пул 1–2 соединения (ТЗ §6.3.2).
- Переменные окружения: `SERVICE_ROLE_KEY`, `INTERNAL_EDGE_TOKEN`, ключи провайдеров (Replicate/OpenRouter/fal.ai/ElevenLabs), ключи платёжных шлюзов.
- CI: линтеры, прогон миграций на тестовой БД, запрет коммита секретов.

## Критерии приёмки (DoD)

- [ ] Воркер стартует и держит 1–2 соединения к Supaviser.
- [ ] Секреты читаются только из env; в репозитории их нет.
- [ ] CI прогоняет миграции на чистой тестовой БД.
