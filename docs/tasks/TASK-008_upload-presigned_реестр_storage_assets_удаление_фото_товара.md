## Цель

Presigned-загрузка в Storage с обязательной регистрацией файла в storage_assets; при удалении товара удалять его product_image-файлы по реестру.

## Что сделать

- Эндпоинт выдаёт signed_url (ttl 900 с) и регистрирует объект (purpose по target).
- Серверная перепроверка после загрузки: ffprobe (длительность/потоки) для видео; лимиты 60 с / 150 МБ.
- DELETE товара: чтение object_name из реестра → удаление объектов /specials/ → удаление записи.
- Лимит 20/час через check_rate_limit.

## Критерии приёмки (DoD)

- [ ] Файл без записи в реестре не остаётся; удалённый товар не оставляет сирот в /specials/.
- [ ] Превышение лимитов → 429/400 до списаний.
