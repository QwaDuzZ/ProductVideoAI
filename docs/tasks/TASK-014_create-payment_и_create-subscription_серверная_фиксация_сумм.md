## Цель

Создание платежа/подписки только сервером: сумма, валюта, кредиты — из пакетов; возврат checkout_url; идемпотентность pending-платежей.

## Что сделать

- create-payment: package_id + gateway; сервер создаёт payments(pending) с event_id-ожиданием; повтор по тому же пакету возвращает существующий pending.
- create-subscription (Ф1): plan_tier из CHECK; активная подписка → 409 ACTIVE_SUBSCRIPTION_EXISTS.
- Ошибки 400/401/404/409/429.

## Критерии приёмки (DoD)

- [ ] Клиент не влияет на сумму/кредиты.
- [ ] Дубль pending не создаёт вторую строку.
