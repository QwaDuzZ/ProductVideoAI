## Цель

Постановка gpu_jobs по схемам §6.5 (Premium 30 One-take; Premium 60 One-take+Extend; Standard 30/60 база+Extend-цепочки); мультимодальный контракт с video_url; фоллбэки провайдеров; ретраи только упавшего Extend; защита базового чанка.

## Что сделать

- Схемы генерации по ТЗ §6.5; idempotency_key на каждый шаг.
- Фоллбэк по §5.2; фоллбэк на низший тариф — только с подтверждением пользователя (UI-флаг в TASK-032).
- Падение Extend: ретраи только Extend; базовый чанк не перегенерируется и не удаляется до завершения цепочки.
- stitch не используется в основном пайплайне.
