## Цель

Степпер 6 шагов; выбор/создание товара; загрузка референса с клиентским сжатием (MP4/H.264/AAC, 480p, ≤30fps, ≤2500kbps, ≤150МБ, ≤60с) и блокировками; настройки SIMPLE/ADVANCED с ценой до подтверждения.

## Что сделать

- Клиентская транскодировка (WebCodecs/ffmpeg.wasm) + проверки до загрузки.
- Браузер без сжатия → сообщение, оригинал не грузится.
- Сегмент-контролы 30/60, standard/premium, fade/loop; цена из ответа сервера; «Больше настроек» раскрывает ADVANCED.
- Референс опционален (пропустить).

## Критерии приёмки (DoD)

- [ ] Файл >60с/150МБ блокируется с текстом из матрицы ошибок.
- [ ] Цена видна до «Продолжить».
