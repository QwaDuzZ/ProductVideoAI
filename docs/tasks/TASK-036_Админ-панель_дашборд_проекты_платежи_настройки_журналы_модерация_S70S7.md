## Цель

Админ-раздел (is_admin): очереди и KPI, принудительный failed с причиной и возвратом, сверка платежей, гейт доноров 31–60 с, вкл/выкл моделей, корректировка баланса с причиной, журналы admin_actions и moderation_events, разбор спорных отказов (Ф1).

## Что сделать

- Все действия пишутся в admin_actions (кто/что/когда/причина).
- Принудительный failed → автовозврат.
- Корректировка баланса только service_role + причина.
- Гейт-флаг доноров логируется; до включения сервер отклоняет 31–60 с.
- Модели: is_active=false исключает из выбора.

## Критерии приёмки (DoD)

- [ ] Любое ручное действие прослеживается в журнале.
- [ ] Доступ только при role=admin.
