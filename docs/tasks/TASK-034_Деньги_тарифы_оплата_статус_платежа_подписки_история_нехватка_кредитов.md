## Цель

## Что сделать

- Суммы/валюта только из ответа create-payment.
- Статус платежа обновляется по вебхуку (polling + realtime).
- История: списания/начисления с причинами.
- S53: «Нужно 70 · у вас 20» + белая «Пополнить».
