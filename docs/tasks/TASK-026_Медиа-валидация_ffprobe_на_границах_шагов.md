## Цель

Единый модуль валидации: контейнер, потоки, длительность ±5%, разрешение, аудио; вызывается после каждого артефакта и перед done; отказ MEDIA_VALIDATION_FAILED с ретраями и автовозвратом.

## Что сделать

- Команда ffprobe по §6.7; допуски ±5%.
- Валидируются: донор, база, Extend-чанки, upscale, финал, озвучка/микс.
- Исчерпание ретраев → failed + возврат (если списано).

## Критерии приёмки (DoD)

- [ ] Битый файл не двигает пайплайн.
