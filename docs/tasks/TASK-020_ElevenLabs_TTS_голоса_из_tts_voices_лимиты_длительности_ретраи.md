## Цель

Озвучка сценария: голос строго по языку проекта из tts_voices; ускорение ≤1.15× при расхождении; ≤2 повторов; автовозврат при TTS_FAILED; регистрация файла в storage_assets.

## Что сделать

- Заполнить tts_voices (ru/en/de/es, elevenlabs, is_active).
- Отсутствие голоса → TTS_VOICE_NOT_FOUND → failed + возврат.
- Длительность озвучки фиксируется ffprobe; расхождение >1 c → ускорение ≤1.15×, иначе TTS_DURATION_MISMATCH.
- audio_mode=original_donor: TTS не вызывается, кредиты не списываются.

## Критерии приёмки (DoD)

- [ ] Язык голоса = язык проекта.
- [ ] Сбой ElevenLabs после повторов → failed + возврат.
