## Цель

Приём платёжных вебхуков: проверка подписи, дедупликация по event_id, сверка суммы/валюты, атомарное начисление, возвраты.

## Что сделать

- Невалидная подпись → 401, не сохраняется.
- event_id UNIQUE: повтор → 200 без начисления.
- Сверка amount/currency с payments; расхождение → failed + алерт.
- succeeded → одна транзакция payments+profiles+credit_transactions; raw_payload/signature_verified/processed_at.
- refunded → списание начисленных кредитов + refund_reason.

## Критерии приёмки (DoD)

- [ ] Нагрузочный тест дублей вебхука: начисление ровно одно.
- [ ] Все ветки покрыты интеграционными тестами.
