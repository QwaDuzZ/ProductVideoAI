## Цель

Служебный эндпоинт воркера: только X-Internal-Token; идемпотентное продвижение статусов по машине состояний; запуск следующих шагов (TTS/video/upscale/audio_mix); обработка результатов измерения Ветки Б.

## Что сделать

- Авторизация токеном; пользовательский доступ 403.
- Повтор по media_task_id не двигает пайплайн дважды.
- Ветка Б: duration_exceeded → failed DONOR_DURATION_EXCEEDED без списаний; иначе расчёт стоимости, charge_credits, → queued.
- Переходы только по таблице §6.1; нарушение → ошибка.

## Критерии приёмки (DoD)

- [ ] Дубль вызова идемпотентен.
- [ ] Невалидный переход статуса отклоняется.
