## Цель

Четыре cron-задачи: очистка Storage с защитой активов, очистка счётчиков лимитов, отказ проектов старше 6 часов, вызов poll-async-jobs каждую минуту.

## Что сделать

- `is_asset_protected()` + `cleanup_temp_storage()` с защитой по storage_assets/проектам/media_tasks/gpu_jobs; cron */15.
- `cleanup-rate-limit-counters` ежечасно (окна старше 24 ч).
- `fail-stuck-projects` */15: активные задачи старше 6 ч → failed + автовозврат.
- `poll-async-jobs` каждую минуту через net.http_post с X-Internal-Token.

## Критерии приёмки (DoD)

- [ ] Активный файл не удаляется очисткой; неактивный по TTL удаляется.
- [ ] Зависший проект через 6 ч → failed + возврат.
- [ ] Polling опрашивает ≤5 задач за цикл, backoff 30/60/120, при 20 попытках — POLLING_EXHAUSTED.
