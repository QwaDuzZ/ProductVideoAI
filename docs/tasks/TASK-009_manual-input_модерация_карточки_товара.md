## Цель

Создание карточки товара с валидацией и контент-модерацией описания/фото до сохранения.

## Что сделать

- Валидация: название 3–200, описание ≤4000.
- Модерация vision/LLM по списку запрещённых тем; отказ CONTENT_POLICY_VIOLATION + запись в moderation_events.
- Лимит операций; ошибки 400/401/429 по контракту.

## Критерии приёмки (DoD)

- [ ] Запрещённый контент не создаёт карточку, списаний нет.
- [ ] Решение модерации логируется (пользователь, материал, категория, модель, время).
